## 배운 것

- **Docker:** 프로그램을 상자(컨테이너)에 담아 실행. 팀원 모두 같은 DB를 파일 하나로 켤 수 있음.
  MariaDB에는 직접 SQL로 말하고, Docker는 켜고 끄는 관리실 역할
- **포트:** PC의 호수. 수업용 DB가 3306을 써서 우리는 3308
- **브랜치:** 사람이 아니라 "일" 단위로 만들고, PR로 합친 뒤 끝냄
- **Flyway:** 번호 붙은 SQL(공사 지시서) + 공사 일지. 이미 한 번호는 건너뜀.
  main에 합친 V 파일은 고치지 않고 새 번호로 추가
- **API는 두 방향:** 남의 창구를 쓰는 것(OpenAI, 키 필요) / 내가 창구를 여는 것(우리 `/api/stocks`)
- **백엔드 API 틀:** Controller(주문) → Service(처리) → Mapper(SQL) → JSON
- **Swagger/springdoc:** 코드를 읽어 API 메뉴판을 자동으로 만들어 줌.
  팀원은 레포를 받아 자기 PC에서 서버를 켜고 확인 (내 서버에 접속하는 게 아님)
- **curl:** 터미널에서 요청 보내는 도구. PowerShell에선 `curl.exe`
