## 15. 언론사 RSS 로 기사 목록 받기 ✅ (2026-11-02)

- 코드: `hk_llm/rss.py` (새 패키지 없음, 표준 라이브러리 XML 파서)
  - `fetch_all()` → `(기사 목록, 실패한 피드)`. 피드 하나가 실패해도 나머지는 계속 받음 (실패는 `common.retry` 로 3번까지 다시)
  - 기사 dict 키 = DB `article` 칸 이름 (V5): `url`, `press`, `title`, `reporter`, `description`, `published_at`
- 확인: `python rss.py`

**실행 결과 (2026-11-02 09시)**

- 총 476건, 주소가 같은 기사 28건 (같은 기사가 경제·증권 피드에 같이 나옴) → 16번에서 제거
- 피드에 담긴 기간: 2026-10-29 ~ 11-02 → 처음 한 번은 며칠치가 들어옴

**처리한 것**
- 시각: 전부 KST(+09:00). 파이낸셜뉴스는 `Mon,2 Nov` 처럼 쉼표 뒤 공백이 없지만 정상 읽힘. 없거나 깨지면 수집 시각
  - Windows 에는 시간대 데이터가 없어 `ZoneInfo("Asia/Seoul")` 대신 고정 +9시간 사용 (한국은 서머타임 없음)
- 기자명: `bng@fnnews.com 김희선` → `김희선`, `도쿄=최만수` → `최만수`
- 제목·링크 없는 항목은 건너뜀

**남은 것**
- 기자명에 사람이 아닌 값이 섞임 (`공시뉴스`, `국제뉴스공용1` 등) → 21번 정제에서 처리
