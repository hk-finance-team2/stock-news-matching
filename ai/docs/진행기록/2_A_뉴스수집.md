**처리한 것과 근거**

| 처리 | 근거 |
|---|---|
| 시각을 `email.utils.parsedate_to_datetime` 으로 읽음 | RSS 2.0 은 `pubDate` 를 RFC 822 형식으로 정함 ([RSS 2.0 규격](https://www.rssboard.org/rss-specification)), Python 이 이 형식을 읽는 함수 제공 ([Python 문서](https://docs.python.org/3/library/email.utils.html#email.utils.parsedate_to_datetime)) |
| 파이낸셜뉴스 `Mon,2 Nov 2026 07:04:55 +0900` (쉼표 뒤 공백 없음)도 정상 | 직접 실행해 `2026-11-02 07:04:55+09:00` 으로 읽히는 것 확인 |
| 시각 없거나 깨지면 수집 시각 | [../결정사항.md](../결정사항.md) 4번 |
| 시간대는 `ZoneInfo("Asia/Seoul")` 대신 고정 +9시간 | Windows 에는 시간대 데이터가 없어 `tzdata` 패키지가 필요 ([Python 문서 zoneinfo Data sources](https://docs.python.org/3/library/zoneinfo.html#data-sources)). 실제로 `ZoneInfoNotFoundError` 발생 확인. 한국은 1988년 이후 서머타임이 없어 +9 고정과 결과가 같음 |
| 연합뉴스 기자명은 `<dc:creator>` 에서 읽음 | 연합뉴스 피드가 Dublin Core 이름공간 `http://purl.org/dc/elements/1.1/` 을 선언하고 `<author>` 대신 씀 (피드 원문 확인) |
| 기자명 `bng@fnnews.com 김희선` → `김희선` | 파이낸셜뉴스 피드 원문. RSS 2.0 규격상 `<author>` 는 원래 메일 주소 자리 |
| 기자명 `도쿄=최만수` → `최만수` | 한국경제 `feed/finance` 피드 원문 (특파원 표기) |
| 제목·링크 없는 항목은 건너뜀 | 화면에 원문 링크·제목이 꼭 필요 (`article.url`, `title` 이 NOT NULL) |
| XML 을 bytes 로 넘김 | 피드가 선언한 인코딩(`<?xml ... encoding=...?>`)을 파서가 따르게. 조사 때 머니투데이가 EUC-KR 이었음 ([../조사/뉴스소스_조사.md](../조사/뉴스소스_조사.md) 1번) |

## 16. URL 기준 중복 제거 ✅ (2026-11-02)

- 코드: `hk_llm/dedup.py`
  - `url_key(url)`: 중복 판단용 주소. DB `article.url_key` 에 그대로 저장 (V5, `VARCHAR(500)`, UNIQUE)
  - `dedup_by_url(articles)`: 각 기사에 `url_key` 를 붙이고 같은 키는 **첫 건만** 남김
  - 이번 실행 안의 중복만 거름. 이미 DB 에 있는 기사는 18번에서 `uk_article_url_key` 로 걸러짐
- 확인: `python dedup.py` → `ok`

**`url_key` 만드는 규칙과 근거**

| 규칙 | 근거 |
|---|---|
| `utm_*`, `ref`, `input` 꼬리 뗌 | [../결정사항.md](../결정사항.md) 4번. 실제 사례: 연합 `?input=1195m`, 서경 `?ref=naver`, 이데일리 `utm_source=naver` ([../조사/뉴스소스_조사.md](../조사/뉴스소스_조사.md) 5번) |
| 기사 번호 꼬리(`newsId` 등)는 남김 | 같은 조사 5번: 이데일리는 `newsId` 가 기사 번호라 떼면 다른 기사가 같아짐 |
| 남은 꼬리는 이름순 정렬 | `?a=1&b=2` 와 `?b=2&a=1` 은 같은 주소 |
| 호스트만 소문자로 | 호스트는 대소문자 구분 없음, 경로는 구분할 수 있음 ([RFC 3986 6.2.2.1](https://www.rfc-editor.org/rfc/rfc3986#section-6.2.2.1)) |
| `#` 뒤는 뗌 | `#` 뒤는 서버로 가지 않음, 같은 문서 안 위치일 뿐 ([RFC 3986 3.5](https://www.rfc-editor.org/rfc/rfc3986#section-3.5)) |
| 끝의 `/` 뗌 | 언론사 기사 주소는 끝 `/` 유무로 다른 기사가 되지 않음 (가정, 문제 생기면 뺌) |
| 500자 넘으면 건너뛰고 로그 | `url_key VARCHAR(500)` (V5). 지금 RSS 주소는 최대 47자 |
| `http`↔`https`, `www.` 유무는 안 맞춤 | 아직 그런 사례를 못 봄 → 생기면 추가 |
