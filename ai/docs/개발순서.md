## E. SNS 🟡 최소 구현 (2026-11-03, `hk_llm/steps/sns.py`)

사용자 판단: SNS 는 형식적으로 둠. 네이버 카페·블로그로 확정, 1~6·8번 완료, 백엔드 API 까지 확인. 7번(팀 확인)과 프론트 화면 E2E 가 남음. 다음 카페는 시험 후 제외. 아래 표는 처음 세운 계획이고, 실제로는 새 글을 `FETCHED` 로 저장하고, 거른 글은 저장하지 않으며, 오래됐을 수 있는 카페 글만 `SKIPPED` 로 번호를 남김 (2026-11-04). 수집처는 유튜브·X 제외

요건: 커뮤니티 글 수집, 광고·도배 거르기(필수), 종목 연결, 종목별 여론 요약과 뉴스 감성 비교(기능정의서 주제 5). 네이버 종토방은 robots 전체 금지라 대체처를 씀 ([조사/SNS_조사.md](조사/SNS_조사.md)).

| 순서 | 원래 번호 | 단계 | 방법 | 끝나는 조건 |
|---|---|---|---|---|
| 1 | - | 수집처 확인 (코드 없음) | 네이버 카페 검색을 API HUB 키로 5종목 시험: 경로, 받는 칸, 작성 시각, 글 품질, 요금·약관 | 🧑 쓸 곳 결정 |
| 2 | - | 뉴스 단계와 분리 | `step4`·`step5`·`step8` 조회에 `source_type` 조건. 먼저 고쳐서 SNS 글이 뉴스 단계로 안 들어가게 | 시험 통과, 뉴스 결과 변화 없음 |
| 3 | 38·40·41 | 수집·중복 제거·저장 | 종목명으로 검색 → `source_type SNS`, `channel NAVER_CAFE`, `LISTED`. 제목·미리보기만, 닉네임 저장 안 함, 본문 안 긁음 | 소량 표본 저장 |
