# 팀 공유 (AI 담당 → 백엔드·프론트·전체)

AI 쪽에서 정한 것과 화면용 데이터 모양. 지금은 이 기준으로 개발 중이고, 팀에서 다르게 정해지면 그 부분만 고친다.

## 1. AI 담당이 정한 것

| 정한 것 | 이유 |
|---|---|
| 뉴스는 **언론사 RSS 8개로 실시간** 수집 (한경·연합·서경·파이낸셜뉴스) | 네이버 API 는 날짜 지정이 안 되고 기사량이 많아 비용이 큼 → 과거 기록용으로만, 나중에 |
| 종목 범위 **코스피200** | 데모에 충분하고 비용 관리 가능 |
| **머니투데이·이데일리 제외** | 본문을 가져올 수 없음 (robots 금지 / 봇 차단) |
| 기사 본문은 **7일 후 삭제**, 요약은 계속 보관 | 언론사 AI 정책상 전문 영구 저장은 위험 |
| 종목 연결이 없는 경제 기사는 버림 | 나중에 시장 브리핑 기능 때 다시 검토 |

## 2. 화면용 데이터

**프론트가 받게 될 기사 1건 예시** (백엔드가 DB 를 읽어 팀 약속대로 camelCase + `+09:00` 로 내보낸 모양, 값은 가짜)

```json
{
  "articleId": 1024,
  "title": "삼성전자, 3분기 영업이익 시장 예상 상회",
  "press": "한국경제",
  "reporter": "홍길동",
  "url": "https://www.hankyung.com/article/2026103012345",
  "publishedAt": "2026-10-30T09:12:00+09:00",
  "summary": "삼성전자 3분기 영업이익이 시장 예상을 웃돌았다. 메모리 가격 상승이 주요 원인이다.",
  "model": "(사용 모델명)",
  "summarizedAt": "2026-10-30T09:40:11+09:00",
  "stocks": [
    {"stockCode": "005930", "stockName": "삼성전자", "isMain": true,  "sentiment": "POSITIVE", "reason": "실적이 예상보다 좋음"},
    {"stockCode": "000660", "stockName": "SK하이닉스", "isMain": false, "sentiment": "NEUTRAL", "reason": "업황 언급만 있음"}
  ]
}
```

- 테이블 제안: [AI테이블_제안.md](AI테이블_제안.md) (`article`, `article_stock`, `collect_run`)
- 백엔드는 `article.status = 'DONE'` 인 기사만 조회, 본문(`body`) 컬럼은 조회하지 않음
- "갱신 시각" = `collect_run` 에서 `status = 'SUCCESS'` 인 가장 최근 `finished_at`

## 3. 백엔드 요청: `article.companies` 칸 추가 (V7) — 2026-11-02 요청

**보낼 메시지 (Slack)**

> 백엔드 님께 DB 칸 하나 추가 부탁드립니다 🙏
>
> **요청**: `article` 테이블에 `companies` 칸 추가 (Flyway 다음 번호, 지금 기준 V7)
> ```sql
> ALTER TABLE article
>     ADD COLUMN companies JSON NULL
>         COMMENT 'LLM 이 뽑은 회사 목록 (종목 매칭 입력). 백엔드·화면은 조회하지 않음'
>         AFTER sentiment;
> ```
> **왜**: AI 요약 단계에서 LLM 이 "기사에 나온 회사 + 회사별 감성·이유"를 뽑는데, 이걸 종목코드로 바꾸는 매칭 단계가 따로 있어서 그 사이에 잠깐 둘 곳이 필요합니다. `article_stock` 은 종목코드가 정해진 뒤에만 넣을 수 있어서 못 씁니다.
> 저장해 두면 매칭 규칙(별칭·오탐·점수)을 고칠 때 **LLM 을 다시 안 불러도** 돼서 비용이 안 듭니다.
>
> **들어갈 값 예시**
> ```json
> [{"name": "포스코퓨처엠", "is_main": true,  "sentiment": "POSITIVE", "reason": "베트남 음극재 공장 착공 3,570억 원"},
>  {"name": "아트박스",     "is_main": false, "sentiment": "POSITIVE", "reason": "카자흐스탄 300만 달러 계약"}]
> ```
> - 비어도 됨 (NULL), AI 만 쓰고 읽음. 화면용 API·백엔드 코드는 바꿀 것 없습니다
> - 화면에 나가는 종목별 감성·이유는 지금처럼 `article_stock` 에 들어갑니다
>
> 언제쯤 가능할지만 알려주시면 그에 맞춰 개발하겠습니다!
