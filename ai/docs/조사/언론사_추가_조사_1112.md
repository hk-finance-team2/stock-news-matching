## 판정에 영향을 주는 것 (수집기와 맞물리는 부분)

1. **매일경제·머니투데이의 "AI학습 이용 금지"**: 문구만 보면 "학습"만 금지(비즈워치 `ai-train=no` 와 비슷)라 FULL 로 볼 여지가 있음.
   그러나 `rights.NOTICE` 정규식이 이 문구를 잡아서, FULL 로 넣어도 기사 2건 뒤 자동으로 TITLE_ONLY 로 바뀜. 게다가 매일경제는 고지의 저작권자가
   "매경AX" 라 `rights.is_wire("매일경제", "매경AX")` 가 True → 모든 기사가 '전재'로 건너뛰어짐. → **지금은 TITLE_ONLY 가 맞음.** FULL 로 하려면 팀이 문구 해석을 정하고 `rights.py` 도 같이 고쳐야 함
2. **이데일리 RSS 링크**는 `http://www.edaily.co.kr/news/newspath.asp?newsid=…` → https → `https://www.edaily.co.kr/News/Read?newsId=…&mediaCodeNo=257` (리다이렉트 2번).
   `step4_body.fetch_bodies` 는 `p.scheme != "https"` 면 "모르는 사이트"로 SKIPPED → 넣으려면 RSS 단계에서 https 로 바꾸거나 `News/Read` 주소로 바꾸는 손질 필요(기사 1건에 요청 3번 → 바꾸면 1번)
3. **pubDate 형식**: 매일경제 `Thu, 12 Nov 2026 10:09:03 +09:00`(시간대에 콜론) → `parsedate_to_datetime` 이 시간대 없는 값으로 읽음(직접 확인). `step1_rss._published` 는 이를 `.astimezone(KST)` 하므로 컨테이너(UTC)에선 9시간 어긋날 수 있음.
   헤럴드경제 `2026-11-12 10:48:42`(시간대 없음) → 지금 코드가 KST 로 봄(맞음). 조선비즈 `+0000` 은 정상
4. **피드 호스트와 기사 호스트가 다름**: 블로터·디일렉·서울파이낸스 피드는 `cdn.*`, 기사는 `www.*` → `BODY_XPATH` 키는 기사 호스트(`www.bloter.net` 등)
5. **robots Crawl-delay**: 블로터·디일렉·서울파이낸스는 `bingbot` 에만 30초, 데일리안은 `Bingbot`·`Yandex` 에만 5초. `*` 에는 없음 → `robots.crawl_delay` 기본 1초
