# robots.txt · 언론사 AI 정책 조사 (2026-10-30)

**왜**: 기사 본문을 직접 가져오는 곳(20번)은 사이트가 허용한 경로만 수집한다. API·RSS 피드 자체는 대상 아님.
확인 방법: 각 RSS 의 실제 기사 URL 로 `can_fetch` 판정.

| 언론사 | 기사 본문 | AI 봇 차단 | 비고 | 방침 |
|---|---|---|---|---|
| 한국경제 | ✅ 허용 | 없음 | `/print/`, `/api/` 등만 금지 | 수집 |
| 연합뉴스 | ✅ 허용 | 🔴 강함 (30여 개) | AI 학습 봇 전부 차단, AI 검색 봇도 기사만 허용 | 수집, 요약+링크만 노출 |
| 서울경제 | ✅ 허용 | 🟡 학습만 | GPTBot·ClaudeBot 차단, 검색·사용자 요청 봇 허용 | 수집 |
| 파이낸셜뉴스 | ✅ 허용 | 없음 | `/print/` 등만 금지 | 수집 |

| SAT경제 | ✅ 허용 | 🔴 강함 | GPTBot, anthropic-ai, CCBot 차단 | (API 쪽, 보류) |

- 🔴 AI 학습·검색 봇 대부분 차단 / 🟡 일부만 / 없음 = AI 봇 규칙 없음
- 네이버 API 원문 링크는 이 표 밖의 언론사도 나옴 → `robots.py` 가 자동 판정

## 눈여겨볼 점

- 연합·매경·머투·서경 등이 `GPTBot`, `ClaudeBot`, `CCBot` 등을 `Disallow: /` 로 막음
- 우리 봇 이름은 목록에 없어 기술적으로는 허용이지만 **AI 용 수집을 원치 않는다는 의사 표시**
- 매일경제 `mk.co.kr/llms.txt` 요약
  - ✅ 허용: 요약·최소한의 인용, RAG, 원문 링크 제공
  - ❌ 금지: AI 학습·데이터셋 제작, **기사 전문 영구 저장**, 원문 대체 수준의 재구성, 유료 기사
- → 우리 설계: 화면엔 **요약 + 원문 링크만**, 본문은 **7일 후 삭제**

## 코드: `hk_llm/robots.py`

- `allowed(url)`: 본문 가져오기 전에 호출. 사이트별 robots.txt 를 한 번만 받아 캐시
- `crawl_delay(url)`: 사이트가 정한 요청 간격, 없으면 1초
- 봇 이름: `hk-llm-news-bot/0.1 (academy student project)` (정체를 숨기지 않음)
- robots.txt 를 못 받으면(네트워크 오류·5xx) 수집 안 함, 없으면(404) 허용
- 확인: `python robots.py` → `ok`
