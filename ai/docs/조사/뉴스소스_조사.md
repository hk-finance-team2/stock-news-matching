## 2. NAVER API HUB 뉴스 검색

- 네이버 개발자센터가 아니라 **NAVER API HUB** (네이버 클라우드 플랫폼) 에서 신청. 결제수단 등록 필수
- 호출: `https://naverapihub.apigw.ntruss.com/search/v1/news`
  - 헤더 `X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY` (옛 헤더 `X-Naver-Client-Id` 는 401)
- 요금: 검색 API 는 월 775,000건·**일 25,000건** 무료, 일 한도에서 막혀 과금 없음. 검색어 트렌드는 3만 건 초과분 유료 구간(현재 한시 무료)
- 응답 특징
  - 제목에 `<b>` 강조 태그, HTML 엔티티(`&quot;`), 중간 `...` 잘림
  - `pubDate` 는 `+0900` 포함 RFC 822 → KST 변환 쉬움
  - 원문 링크가 여러 언론사로 흩어짐 → 언론사마다 robots.txt 자동 확인 필요
- ❌ **날짜 지정 검색 불가**: `startDate`, `ds/de` 등 넣어도 무시됨
- ❌ **최신 1,000건까지만**: `start=1001` → 400 "부적절한 start 값"

## 5. 같은 기사가 다른 주소로 오는 예 (RSS vs API)

| 언론사 | RSS 주소 | 네이버 API 주소 |
|---|---|---|
| 연합뉴스 | `yna.co.kr/view/AKR20261030137800008` | 같은 주소 + `?input=1195m` |
| 서울경제 | `sedaily.com/article/20108364` | 같은 주소 + `?ref=naver` |
| 한국경제 | `hankyung.com/article/202610306351i` | 같은 주소 |
| 이데일리 | - | `...Read?newsId=0511...&mediaCodeNo=257&utm_source=naver&...` (`newsId` 는 기사 번호) |

- 다른 언론사가 같은 제목으로 쓴 기사(`[속보] 코스피 3.48% 급락` 한경 vs 노컷뉴스)는 주소가 완전히 다름 → 제목 유사도로 묶어야 함
