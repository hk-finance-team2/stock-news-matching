# SNS·커뮤니티 수집처 조사 (2026-11-02)

**왜**: 기능정의서의 필수 항목 "종토방 수집" 은 네이버 금융이 robots.txt 로 전체 금지한다. 대신 쓸 곳을 찾았다. 조건은 ① 허용된 경로 ② 공신력 있고 너무 이상하지 않은 커뮤니티 (사용자 요청).

**방법**: 우리 봇 이름으로 robots.txt 와 페이지를 곳당 몇 번만 요청. 이용약관 전문은 확인하지 않았다.

| 곳 | 신뢰도 느낌 | robots.txt | 확인한 것 | 판단 |
|---|---|---|---|---|
| 네이버 카페 검색 API | 카페에 따라 다름 | 공식 API | API HUB 키로 동작, **작성 시각 없음**, 쓸 만한 글 약 7% (2026-11-03, [시험 기록](../진행기록/4_E_SNS.md)) | 1순위 후보. 시각 대체 방법 필요 |

- 네이버 카페 API: 지금 키로 되는지, 비용, 받는 칸 (제목·미리보기만일 것으로 예상, 미확인)
- 네이버 종토방 대체: 정해진 요건 없음 (2026-11-02 사용자 확인) → 강사 확인 불필요
- 쓰기로 한 곳의 이용약관

## 추가 조사 (2026-11-03, 사용자 요청)

**방법**: 웹 검색, 공식 문서 읽기, 우리 봇으로 robots.txt 확인 (`old/실험스크립트/sns_robots.py`). 뽐뿌 RSS 1번, Bluesky 1번 직접 요청. 이용약관은 아직 안 읽음. "AI 봇 항목" 은 robots.txt 에 그 봇 이름이 있다는 뜻이고 규칙 내용까지 확인한 것은 아님

| 곳 | 받는 방법 | 작성 시각 | 종목별 | 확인한 것 | 판단 |
|---|---|---|---|---|---|
| 뽐뿌 증권포럼 | RSS `rss.php?id=stock` | ✅ `pubDate` | ❌ 코드로 연결 | HTTP 200, 15건이 약 30분치, 개인 의견 글 위주. robots 허용, AI 봇 항목 없음 | **추천**. 작성자 칸은 저장 안 함 |
| 다음 카페 검색 API | 공식 API `v2/search/cafe`, 카카오 키 필요 | ✅ `datetime` 초 단위 | 검색어 | [개발 문서](https://developers.kakao.com/docs/ko/daum-search/dev-guide), [쿼터](https://developers.kakao.com/docs/ko/getting-started/quota): 일 30,000건 무료. 키가 없어 글 품질은 미확인 | **추천**. 키 발급 후 시험 |
| 네이버 카페 검색 API | 공식 API | ❌ 없음 | 검색어 | [문서](https://api.ncloud-docs.com/docs/naver-api-hub-search-cafearticle.md): 일 25,000회. 요금은 문서에 없음. `lastBuildDate` 는 검색 시각 | 보조 |
| 네이버 블로그 검색 API | 공식 API | 날짜만 | 검색어 | 시험 완료, 정보·분석 글 위주 | 보조 |
| 유튜브 데이터 API | 공식 API, 키 필요 | 미확인 | 영상 찾기 필요 | [쿼터](https://developers.google.com/youtube/v3/determine_quota_cost): 댓글 조회 1단위, 검색은 하루 100번. 저장 30일 제한은 2차 자료로만 봄 | 대안. 채널을 정해야 함 |
| Threads | 공식 API | 미확인 | 검색어 | [문서](https://developers.facebook.com/documentation/threads/keyword-search): 공개 글 검색은 Meta 승인 필요. 웹은 우리 봇 금지 | 승인이 어려우면 불가 |
| 토스증권 Open API | 공식 API | - | - | 시세·계좌·주문용으로 소개됨, 커뮤니티 언급 없음 ([기사](https://economist.co.kr/article/view/ecn202608130015)). 비공식 내부 API 는 쓰지 않음 | 커뮤니티 수집 불가로 봄 |
| 네이버 주주오픈톡, NH·키움 앱 커뮤니티 | 앱 안 | - | - | 공개 수집 경로를 못 찾음 | 제외 |
| 클리앙 주식, 더쿠 | 웹 | - | - | robots 에 AI 봇 항목 있음 | 제외 |
| Bluesky | 공개 API | - | - | 검색 HTTP 403. 한국 주식 글이 많을지도 미확인 | 제외 |

- **쓰는 곳: 네이버 카페·블로그 검색 API** (2026-11-03 확정)
- 다음 카페: 시험 후 제외. 최근 글이 적음 ([시험 기록](../진행기록/4_E_SNS.md))

- 토스증권: 정식 서비스지만 커뮤니티 글을 받는 공식 경로를 못 찾음. 비공식 내부 API 는 쓰지 않음
