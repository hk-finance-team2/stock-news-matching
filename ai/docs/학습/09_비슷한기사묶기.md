# 9. 비슷한 기사 묶기 (`step7_group.py`, 개발순서 17번)

## 한 줄 요약

같은 사건을 다룬 기사를 **지우지 않고 묶는다.** 조건은 같은 종목 + 비슷한 제목 + 24시간 이내. 아직 DB 에 저장하지는 않는다.

## 왜 필요한가

언론사가 7곳이라 같은 소식이 여러 건 들어온다. 그대로 두면 종목 화면에 비슷한 줄이 반복된다.

## 들어가고 나오는 것

| | 내용 |
|---|---|
| 들어감 | `DONE` 기사와 연결된 종목 (`article_id`, `stock_code`, `stock_name`, `title`, `published_at`) |
| 나옴 | `[{stock_code, stock_name, article_ids}]`, 2건 이상인 묶음만 |
| DB | 읽기만 (저장 칸은 백엔드에 요청 예정) |

## 코드 따라 읽기

**① 제목 다듬기 (`_bigrams`)** — `[속보]`, `(종합)`, 기호, 공백, **종목명**을 빼고 글자 2개씩 자른다.
```
"HL만도, 3분기 실적 부진" → 종목명 뺀 "3분기실적부진" → {3분, 분기, 기실, 실적, 적부, 부진}
```
종목명을 빼는 이유: 같은 종목 기사는 이름이 항상 겹쳐서, 다른 사건도 비슷해 보이기 때문이다.

**② 유사도 (`similarity`)** — 겹친 조각 수 ÷ 전체 조각 수 (Jaccard). 0 ~ 1.

**③ 묶기 (`group_articles`)** — 종목별로 모든 쌍을 비교한다. A-B, B-C 가 비슷하면 A·B·C 가 한 묶음이다 (`find` 가 같은 묶음 찾기).

## 기준값 0.15 는 어떻게 정했나

추측하지 않고 수집한 실제 제목 쌍 179개를 읽어 봤다.

| 점수 | 본 결과 |
|---|---|
| 0.15 이상 | 같은 사건 |
| 0.10 ~ 0.15 | 같은 사건이 많지만 시황 기사끼리 섞임 |
| 0.05 이하 | 다른 소식 섞임 |

**한계**: 제목을 읽고 판단한 임시값이다. 실제 기사가 쌓이면 다시 본다. 포스코퓨처엠 실적 기사(0.12)처럼 표현이 많이 다른 같은 사건은 놓친다.

## 왜 종목이 먼저인가

`HLB` 와 `HLB제약` 제목은 거의 같아도(0.83) **다른 회사**다. 제목만으로 묶으면 다른 회사 기사가 합쳐져서, 종목을 알고 난 뒤에 묶는다.
