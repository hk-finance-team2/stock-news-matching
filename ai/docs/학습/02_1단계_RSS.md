# 2. 1단계: RSS 11개에서 기사 목록 받기 (`step1_rss.py`, 개발순서 15번)

## 한 줄 요약

언론사 7곳의 **RSS 11개**를 받아서, 기사마다 `Article` 하나로 만든다. 지금 한 번에 약 1,080건 (비즈워치 피드가 2주치 475건이라 많음).

## 왜 필요한가

- 뉴스를 모으는 입구. 여기서 **제목·링크·기자·발행 시각**을 얻는다
- RSS 에는 **본문이 없다** (조사 결과: 짧은 요약문만 있거나 아예 없음) → 본문은 4단계에서 따로

## 들어가고 나오는 것

| | 내용 |
|---|---|
| 들어감 | RSS 주소 11개 (`FEEDS`) |
| 나옴 | `Article` 목록 (~1,080건, 중복 포함) + 실패한 피드 주소 목록 |
| DB | 안 건드림 |

## RSS 는 이렇게 생겼다

```xml
<rss><channel>
  <item>
    <title>삼성전자 급등</title>
    <link>https://www.fnnews.com/news/1</link>
    <author>bng@fnnews.com 김희선</author>
    <pubDate>Mon, 2 Nov 2026 07:04:55 +0900</pubDate>
  </item>
  <item> … 다음 기사 … </item>
</channel></rss>
```
`<item>` 하나 = 기사 하나.

## 코드 따라 읽기

**① 받을 주소 (`FEEDS`)**
```python
FEEDS = {
    "한국경제": [".../feed/finance", ".../feed/economy"],
    "연합뉴스": [".../rss/economy.xml", ".../rss/market.xml"],
    "서울경제": [...], "파이낸셜뉴스": [...],
    "전자신문": [".../02.xml"], "연합인포맥스": [".../allArticle.xml"], "비즈워치": [".../rss"],
}
```
언론사 이름 → 주소 목록. 소스를 바꾸려면 여기와 4단계 `BODY_XPATH` 를 고치면 된다.

**② 전부 받기 (`fetch_all`)**
```python
for press, urls in FEEDS.items():
    for url in urls:
        try:
            articles += fetch_feed(url, press)
        except Exception as e:
            failed.append(url)          # 하나 실패해도 나머지는 계속
```

**③ 피드 하나 받기 (`fetch_feed`)** → `retry` 로 감싸서 요청 → `parse` 로 넘김

**④ XML 을 Article 로 (`parse`)** — `<item>` 마다:

| 꺼내는 것 | 처리 | 함수 |
|---|---|---|
| 제목·링크 | 둘 중 하나라도 없으면 버림 | `_text` |
| 기자명 | `"bng@fnnews.com 김희선"` → `김희선`, `"도쿄=최만수"` → `최만수`, `"a@bizwatch.co.kr(강민경 기자)"` → `강민경` | `_reporter` |
| 발행 시각 | 한국 시간(KST)으로 변환. 언론사마다 형식이 달라 세 가지를 읽음 (`Mon, 2 Nov 2026 …`, `2026-11-02T15:19:02+09:00`, 시간대 없는 `2026-11-02 15:17:18` = KST). 없거나 깨지면 **지금 시각** | `_published` |
| 요약문 | 있으면 저장 | `_text(it, "description")` |

연합뉴스만 기자명이 `<dc:creator>` 라는 다른 태그에 있어서 `_text(it, "author") or _text(it, DC + "creator")` 로 둘 다 본다.

## 왜 이 언론사들인가 (결정사항 1번)

- 머니투데이: robots.txt 가 본문 수집 금지 → 제외
- 이데일리: 기사 페이지가 우리 봇에게 404 → 제외 (브라우저인 척 우회 안 함)
- 매일경제: RSS 자체가 403 차단 → 제외
- 네이버 뉴스: robots.txt 전체 금지 → 제외
- 구글 뉴스: robots.txt 전체 금지, 링크가 구글 주소라 본문을 못 가져옴 → 제외
- 조선비즈: robots.txt 가 AI 목적 보관 사본을 금지 → 제외

외부에서 받은 XML 은 `defusedxml` 로 읽는다. 악의적인 XML(엔티티 폭탄 등)로 프로그램이 멈추는 걸 막기 위해.
