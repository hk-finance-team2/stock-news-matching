# 11. 자동 실행과 AI 서버

**한 줄 요약**: `loop.py` 가 5분마다 파이프라인을 돌리고, `api.py` 는 백엔드의 "다시 생성" 요청을 받는다.

## 왜 필요한가

지금까지는 사람이 `python -m hk_llm.run` 을 칠 때만 기사가 들어왔다. 서비스가 되려면 혼자 돌아야 한다. "다시 생성" 버튼은 사람이 누른 순간 요약을 만들어야 해서 요청을 받을 서버가 따로 필요하다.

## 들어가고 나오는 것

| 프로그램 | 들어가는 것 | 나오는 것 |
|---|---|---|
| `hk_llm/loop.py` | 없음 (시간이 되면 스스로 시작) | `article`, `article_stock`, `stock_daily_summary`, `collect_run` |
| `hk_llm/api.py` | `POST /summaries/{종목코드}` + 토큰 | 오늘 요약 JSON |

둘은 서로를 모른다. 같은 DB 를 쓸 뿐이다.

## 코드 따라 읽기

**`wait_seconds(now)`**: `300 - now % 300`. 지금이 14:58:00 이면 2분을 기다린다. 실행이 5분을 넘어 15:07 에 끝나면 15:10 까지 기다리므로 지나간 차례(15:05)는 자연스럽게 건너뛴다.

**`done_hour`**: 하루 요약을 돌린 시각(시 단위)을 기억한다. 시가 바뀌면 다르니까 `daily=True` 가 된다. 실행이 실패하면 값을 안 바꾸므로 다음 차례에 다시 시도한다.

**`GET_LOCK('hk_llm_run', 0)`**: DB 에 이름표를 건다. 두 번째 프로그램은 바로 0 을 받아 실행을 건너뛴다. 비용이 두 번 나가는 일을 막는다. 프로그램이 죽으면 DB 연결이 끊기며 이름표도 풀린다. 다만 SQLAlchemy 는 연결을 끊지 않고 재사용하므로, 정상 종료 때는 `RELEASE_LOCK` 으로 직접 푼다.

**죽은 `RUNNING` 정리**: 이름표를 잡았다면 지금 도는 실행은 없다. 그러니 `RUNNING` 으로 남은 줄은 전부 비정상 종료된 것이다. 안 고치면 화면이 계속 "수집 중" 이다.

**`regenerate_summary`** (`api.py`): 순서대로 토큰 확인 → 저장된 요약이 10분 안에 만들어졌으면 그대로 돌려줌 → 아니면 새로 만듦. 이 API 를 부를 때마다 돈이 나가므로 토큰과 10분 제한을 둔다. `secrets.compare_digest` 는 토큰 비교 시간으로 값을 추측하지 못하게 하는 비교 함수다.

**`document_text`** (`dart.py`): DART 원문은 zip 으로 온다. 압축을 풀어 CSS(`style`)를 빼고 글자만 남긴다. 파일이 `euc-kr` 이라고 적혀 있어도 실제로는 UTF-8 인 경우가 있어서, UTF-8 로 먼저 읽어 보고 안 되면 CP949 로 읽는다.

**`save_groups`** (`step7_group.py`): 칸이 있는지 `information_schema` 로 먼저 본다. 없으면 아무것도 안 한다. 그래서 백엔드가 칸을 추가하면 코드를 안 고쳐도 저장이 시작된다.

## 직접 해보기

비용이 없는 것:

```bash
python -m tests
```

AI 서버 켜고 상태 보기 (`.env` 에 `AI_INTERNAL_TOKEN` 필요):

```bash
uvicorn hk_llm.api:app --port 8000
```

브라우저에서 `http://localhost:8000/docs` 를 열면 API 목록이 보인다.

자동 실행 (⚠️ 켜 두는 동안 비용 발생, 처음에는 밀린 기사까지 최대 약 $0.8):

```bash
python -m hk_llm.loop
```
