**읽는 법**
- 각 문서는 `한 줄 요약 → 왜 필요 → 들어가고 나오는 것 → 코드 따라 읽기 → 직접 해보기 → 확인 질문` 순서
- 코드 파일을 옆에 열어 두고 같이 보면 좋음
- "직접 해보기" 명령은 전부 `ai` 폴더에서, 가상환경 켠 상태로 (`.venv\Scripts\activate`)
- 확인 질문의 답은 `▶ 답 보기` 를 눌러서
