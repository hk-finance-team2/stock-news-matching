# 1. 코드 읽기 기초

이 프로젝트 코드에 반복해서 나오는 것만 모았다. 파이썬 전체 문법이 아니라 **여기 코드를 읽는 데 필요한 것**만.

## `python -m hk_llm.run` 은 무슨 뜻?

- `hk_llm` 은 **패키지**(코드 폴더), `run` 은 그 안의 `run.py`
- `-m` 으로 실행하면 파이썬이 **`ai` 폴더를 기준**으로 `hk_llm` 을 찾는다
- 그래서 파일 안에서 `from hk_llm.core.db import get_engine` 처럼 다른 파일을 불러올 수 있다
- `python hk_llm/run.py` 로 실행하면 `hk_llm` 을 못 찾아서 오류가 난다 → **항상 `ai` 폴더에서 `python -m`**

## import: 다른 파일의 함수 가져오기

```python
from hk_llm.steps.step2_dedup import dedup_by_url   # step2_dedup.py 안의 dedup_by_url 함수
```
파일 맨 위 import 줄만 보면 **이 파일이 누구를 쓰는지** 알 수 있다. 예: `run.py` 는 step1~4 를 다 import → 지휘하는 파일.

## dataclass: 데이터의 모양 정하기 (`models.py`)

```python
@dataclass
class Article:
    url: str                       # 꼭 있어야 함
    press: str
    title: str
    published_at: datetime
    reporter: str | None = None    # 없어도 됨 (기본값 None)
    channel: str = "RSS"           # 안 주면 "RSS"
```
- 새로 받은 기사 한 건 = `Article` 하나. 칸 이름은 DB `article` 테이블과 같다 (1~3단계에서만 씀, 4단계부터는 DB 를 직접 읽음)
- `str | None = None` → "글자이거나 비어 있음, 안 주면 비어 있음"
- 만들기: `Article(url="https://…", press="연합뉴스", title="…", published_at=…)`
- 꺼내기: `a.title`, `a.url_key`

## docstring: 파일·함수 맨 위의 `"""…"""`

```python
"""3단계 (18번): 기사 목록을 article 테이블에 LISTED 로 저장
...
"""
```
**설명문**이다. 실행에는 영향 없음. 파일을 열면 맨 위 docstring 부터 읽으면 그 파일이 뭘 하는지 안다.

## 시험: `tests/` 폴더

실제 기사 없이 규칙만 확인하는 시험은 `tests/` 에 있다.
```python
def test_step2_dedup():
    assert url_key("https://a.com/x?ref=naver") == "https://a.com/x"
```
- `python -m tests` 로 전부 실행한다. 프로그램을 실행할 때는 돌지 않는다
- `assert 조건` → 조건이 거짓이면 그 자리에서 오류로 멈춤
- 전부 통과하면 `11/11 통과` 처럼 나온다. **코드를 고친 뒤 이걸 돌려서 망가졌는지 확인**
- 단계 파일 맨 아래 `if __name__ == "__main__":` 은 그 파일을 **직접 실행했을 때만** 돌고, 실제 기사·API 로 확인한다

## 로그: `log.info(...)`

```python
log = get_logger(__name__)
log.info("RSS 수집 끝: 받은 %d건", n)
```
- `print` 대신 쓴다. 화면 + `hk_llm/logs/hk_llm.log` 파일에 시각과 함께 남는다
- `%d` 자리에 뒤의 숫자가 들어감
- 등급: `info` 보통, `warning` 주의(재시도 등), `error`/`exception` 실패

## 재시도: `retry(lambda: ...)`

```python
res = retry(lambda: requests.get(url, timeout=15))
```
- `lambda: …` = "나중에 실행할 작업"을 통째로 넘김
- `retry` 가 실행해 보고, 네트워크 끊김·서버 오류면 2초·4초 쉬고 다시 (최대 3번)
- 404 처럼 다시 해도 같은 오류는 바로 포기

## DB 다루기: SQLAlchemy `text(...)`

```python
with engine.begin() as conn:                       # 연결 열기 (끝나면 자동 저장·닫기)
    conn.execute(text("UPDATE article SET status = :status WHERE article_id = :id"),
                 {"status": "FETCHED", "id": 5})
```
- SQL 을 직접 쓰고, 값은 `:이름` 자리에 넣는다 (직접 문자열로 끼워 넣지 않음 → SQL 주입 공격 방지)
- `engine.begin()` = 쓰기용 (끝나면 저장), `engine.connect()` = 읽기용

## `.env` 와 `config.py`

- `.env` (레포 최상위, Git 제외) 에 `DB_PASSWORD=…`, `OPENAI_API_KEY=…` 등
- `config.py` 가 그걸 읽어서 다른 파일에 넘겨줌. **비밀번호를 코드에 직접 쓰지 않는다** (팀 규칙)

## 직접 해보기

```bash
python -m tests                      # 11/11 통과
python -m hk_llm.steps.step2_dedup   # 실제 RSS 로 ok 490 → 457 처럼 나옴
```
`tests/test_collect.py` 의 `test_step2_dedup` 에서 assert 하나의 기대값을 일부러 틀리게 바꾸고 다시 실행 → `AssertionError` 가 나는지 보고, 원래대로 되돌리기.
