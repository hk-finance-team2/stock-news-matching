# 간접 연결(INDIRECT) 실험 기록 — 1차 서비스에는 넣지 않음 (2026-11-04)

회사 이름이 없는 이슈 기사를 영향받는 종목에 잇는 기능 (F-05 간접 연결, 주제의 차별점).
예) "중동 긴장에 국제유가 급등" → S-Oil(호재: 정제마진), 대한항공(악재: 연료비)

**결론:** 독립 정답지로 재 보니 Precision 16.7% → 틀린 연결을 사용자에게 보여 줄 수 없어 1차에서는 넣지 않음.
코드(`hk_llm/steps/step6b_indirect.py`)와 평가 도구(`eval/indirect.py`)는 남겨 두고, 시간이 남으면 아래 "다음에 할 일"로 이어 감.

## 방법 (A안)

```
① 경제 이슈 기사만 고름: 제목·키워드에 유가·환율·금리·관세·수출·원자재·운임·정책 등 (정치·사건·포토 제외)
② 후보는 코드가: 종목 사전 테마 37개마다 최근 30일 뉴스에 많이 나온 종목 상위 5개
③ LLM(gpt-5.4-mini)이 기사 1건에 1번: 영향받는 테마 + 후보 안에서 0~3개 종목 + 호재/악재 + 경로 한 문장 + 근거 문장 + 확신도
④ 코드 검사: 후보 밖·중립·확신 HIGH 아님·근거가 기사에 그대로 없음·기사에 이름이 나온 회사·테마당 2개 초과 → 버림
```

## 연습 (연습용 20건, 규칙을 정할 때만 봄)

| 회차 | 바꾼 것 | 결과 (직접 읽고 판정) |
|---|---|---|
| 1 | NO_STOCK 무작위 + gpt-5.4-nano | 13건 연결, 대부분 억지 ("판단 어렵다"면서 연결, 기사에 이름이 나온 회사, 시황 기사) |
| 2 | 경제 이슈 기사만 + mini + 중립·이름 나온 회사·근거 없는 답 버림 | 12건, 좋은 것 약 절반 (유가→정유·항공, 원전 발주→원전 기자재) |
| 3 | + 확신도 HIGH 만, 규모·자회사 규칙 | 4건, 대부분 교과서적 |

같은 기사도 실행마다 답이 흔들림 (nano 에서 심함). 코드 검사가 결과를 안정시킴.

## 평가 (새 이슈 기사 30건, 연습용·기존 정답지와 겹치지 않음)

| 항목 | 결과 |
|---|---|
| 두 심판 (서로 모르게 라벨링) | 30건 모두 완전히 같음, 연결 일치도 **1.000** |
| 정답 간접 연결 | 2건에 4개 (모두 호재) — 기사 안에 업종 가격·수치 경로가 구체적으로 나온 경우만 |
| 시스템 | 5건에 12개 |
| **Precision** | **0.167** (12개 중 2개 맞음) |
| Recall | 0.500 (4개 중 2개) |

### 왜 틀렸나 (심판 메모 기준, 일반화)

- **추측이 두 단계**: 군사행동 "준비" 보도 → (일어나면) 유가 → 정유·항공. 심판은 이미 일어난 사건만 연결
- **"계획" 단계**: 해외 경쟁사가 국내 진출을 계획 → 국내 업체 악재. 규모 판단이 갈림
- 시스템은 "그럴 수 있다"는 추론을 연결하고, 심판은 **기사에 경로가 구체적으로 쓰여 있을 때만** 연결함
- 연습 회차에서 그럴듯해 보인 것은 개발자(나) 판단이었고, 독립 정답지로 재니 크게 달랐음 → 따로 재지 않았으면 틀린 연결을 넣을 뻔함

## 비용

연습 3회 + 평가 1회 = mini 약 90번 (입력 약 25만 토큰). 정확한 금액은 OpenAI 사용량 화면 기준.

## 다음에 할 일 (B안, 시간이 남으면)

1. 규칙 추가: 기사 안에 **그 업종 이름(정유·항공 등)과 영향(가격·수요·비용)이 직접 쓰여 있을 때만**, 아직 일어나지 않은 사건("준비", "계획", "검토")은 제외
2. 연습용 20건으로만 다듬고, **또 다른 새 이슈 기사 30건**으로 평가 (지금 평가 30건은 점수만 봤고 내용은 보지 않았지만, 다시 쓰면 과적합 위험)
3. Precision 70% 이상이면 화면에 "AI 추정 · 참고용 (이슈 영향)"으로 직접 연결과 구분해 표시, 관련도는 직접 연결보다 낮게
4. 저장할 때 `step6` 다시 매칭이 간접 연결을 지우지 않게 (지금은 기사마다 연결을 모두 지우고 다시 넣음)

## 다시 해 보는 법 (ai 폴더)

```
python -m hk_llm.steps.step6b_indirect --trial 20   # 연습용 20건 (DB 에 안 씀)
python -m eval.indirect predict                     # 평가용 30건 시스템 답
python -m eval.indirect score                       # P·R, 두 심판 일치
```
