## 1. 기사마다 적는 것

기사 1건마다 "이 기사와 연결돼야 하는 상장 종목" 목록. 하나도 없으면 **연결 없음** (이것도 정답).

| 칸 | 값 | 뜻 |
|---|---|---|
| 종목 | 종목코드 | 코스피·코스닥 상장 종목만 |
| 역할 | `SUBJECT` 주인공 / `PARTY` 당사자 / `COMPARISON` 비교 | 아래 2절 |
| 감성 | `POSITIVE` 호재 / `NEGATIVE` 악재 / `NEUTRAL` 중립 / `UNCERTAIN` 판단 보류 | 아래 3절 |
| 사실 종류 | `FACT` 일어난 일 / `PLAN` 회사 계획 / `FORECAST` 전망·의견 / `RUMOR` 소문 | 감성을 판단한 문장이 어느 것인가 |
| 근거 문장 | 문장 번호 1개 | 이 종목을 연결한 이유가 가장 잘 드러난 문장 (화면에 번호가 붙어 나옴) |
| 확신 | 높음 / 낮음 | LLM 라벨이 스스로 표시. 결과를 "확신 높은 것"과 "전체"로 나눠 보고함 (Financial PhraseBank 의 일치도별 부분집합 방식) |

## 2. 역할 — 연결할까, 어떤 역할인가

| 역할 | 기준 | 예 |
|---|---|---|
| **주인공** `SUBJECT` | 기사가 그 회사 이야기. 보통 제목에 나오고 기사 대부분이 그 회사 사실 | "삼성전자, 3분기 영업이익 시장 예상 상회" → 삼성전자 |
| **당사자** `PARTY` | 기사 사건에 직접 얽힌 상대: 거래·수주 상대, 인수 대상, 소송 상대, 공급사·고객사로 **구체적 내용**(금액·물량·계약)이 있음 | "현대차, 포스코퓨처엠 베트남 음극재 사업에 1천억 투자" → 현대차 주인공, 포스코퓨처엠 당사자 |
| **비교** `COMPARISON` | 주인공 없이 여러 회사의 **구체 수치**를 나란히 다룸 (업계 비교, 4대 금융 실적 비교) | "4대 금융 3분기 NPL 비율 비교" → 4개 모두 비교 |
| 연결 안 함: 나열 | 이름만 나옴: 시황 등락 목록, 명단, 행사 참가사·연사, 관련 기사 목록, "A·B·C 등" | "코스피 상승 종목은 A·B·C" |
| 연결 안 함: 출처 | 의견을 낸 쪽: 리포트를 쓴 증권사, 자료를 낸 기관 | "키움증권, 해성DS 목표가↓" → 키움증권은 연결 안 함 |

v1 7절의 팀 정책(그룹명만 나오면 연결 안 함, 비상장 자회사는 모회사에 연결 안 함, 증권사 리포트 모음은 꼭지마다 당사자, 펀드·ETF 상품 이름은 운용사 연결 안 함, 간접 연결 기준)은 **그대로**.

애매하면 연결하지 않음 (팀 원칙: 잘못 연결 < 못 찾음). 단, 주인공을 빠뜨리지는 않게.

## 3. 감성 — 무엇을 기준으로 호재·악재인가

**기준 한 줄:** 이 회사 주식을 **지금 가진 주주**에게, **기사에 적힌 사실**이 **다음 거래일까지** 좋은 소식인가 나쁜 소식인가.

- 실제 주가가 올랐는지는 보지 않음 (기사 밖 정보. 주가와의 비교는 따로 검증함)
- 기자의 형용사·말투("훈풍", "먹구름")가 아니라 **사실**(실적·계약·수주·규제·소송·가격)로 판단

| 감성 | 기준 |
|---|---|
| 호재 `POSITIVE` | 이익·매출·수주·가격·점유율·주주환원처럼 회사 가치에 유리한 사실이 있고, **규모나 비교 기준**(시장 전망치, 전년, 회사 규모)이 기사에 있음 |
| 악재 `NEGATIVE` | 같은 기준으로 불리한 사실 (손실, 계약 해지, 제재, 소송 패소, 생산 중단, 대규모 유상증자 등) |
| 중립 `NEUTRAL` | 영향이 없거나 규모를 알 수 없음: 홍보·수상·인사·행사·협약·사회공헌, 이미 지난 주가 움직임만 전하는 기사, 일정 공지 |
| 판단 보류 `UNCERTAIN` | 판단할 사실이 **전망·의견·소문뿐**이거나, 유리한 사실과 불리한 사실이 **비슷한 무게로 섞여** 한쪽으로 못 정함 |

세부 규칙:

1. **실적:** 시장 전망치(컨센서스)와의 비교가 있으면 그것만 봄. 전년보다 늘어도 전망치를 밑돌면 호재 아님(악재 또는 중립). 전망치 비교가 없으면 전년 대비 방향으로 보되, 기사가 "소폭"·"보합"·"예상 수준"처럼 **변화가 작다고 쓰면 중립** (숫자 기준은 근거가 없어 두지 않음)
2. **사실 종류:** 감성은 `FACT`·`PLAN`(회사가 공식 발표한 계획) 문장으로 판단. `FORECAST`(증권사·기자 전망)·`RUMOR`("~알려졌다", "~관측", "업계에 따르면", "~가능성")만 있으면 **판단 보류**
3. **섞인 소식:** 제목·첫 문단이 한쪽을 중심으로 삼으면 그쪽, 아니면 판단 보류
4. **같은 기사, 종목마다 다름:** 유가 급등 → 정유 호재, 항공 악재. 수주 기사 → 수주한 회사 호재, 발주처는 보통 중립
5. **주가 움직임 기사(특징주):** 원인 사실이 기사에 있으면 그 사실로 판단. "급등했다"만 있고 원인이 없으면 중립 (이미 반영된 가격)

중립과 판단 보류의 차이: 중립 = "판단했더니 영향 없음", 판단 보류 = "판단할 근거가 모자람". 시스템의 감성 `NULL`(판단 안 함)과 같은 뜻으로 맞춤.

## 4. 근거 문장

- 화면의 본문 앞에 문장 번호가 붙어 나옴. 그 종목의 역할·감성이 가장 잘 드러난 **한 문장**을 고름
- 제목이 가장 잘 드러내면 0번(제목)
- 이 칸으로 시스템이 고른 근거가 맞는지 채점함 (멘토 지적 h)

## 5. 정답지 만드는 절차 (사람 2명, 합쳐 약 45분)

원칙: **사람은 금융 지식이 필요 없는 일(독해: 어느 회사 이야기인가)만**, 금융 판단(호재·악재)은 사람 대신 **바깥 기준 두 개**로 확인.

| 단계 | 누가 | 내용 | 시간 |
|---|---|---|---|
| ① 표본 | 코드 | 본문을 써도 되는 언론사(`press_policy` FULL) 뉴스 중 **시스템 결과와 상관없이** 무작위. 난수 씨앗 기록. **개발용 100 + 봉인 시험용 100**. 본문은 `data/eval/`에 2026-11-20까지 | 0 |
| ② LLM 라벨 | Claude (시스템과 다른 회사 모델) | 이 문서를 그대로 지시로 주고 200건 전부 라벨. 시스템 답은 보여 주지 않음 | 0 |
| ③ 직접 라벨 A | 검수자 1 (승현님) | 개발용 중 **20건**: 답을 **보지 않고** 연결할 회사와 역할(주인공·당사자·비교)만 고름 | 약 15분 |
| ④ 직접 라벨 B | 검수자 2 (호현님 또는 서준님) | ③과 **같은 20건**을 따로, 서로 답을 보지 않고 | 약 15분 |
| ⑤ 검수 | 검수자 1 (승현님) | 다른 30건: LLM 이 고른 연결마다 **맞다 / 아니다** + 기사마다 "빠진 회사 있나". 함정 문항 5개 포함 | 약 15분 |
| ⑥ 감성 바깥 기준 1 | 코드 | 공개 한국어 금융 감성 데이터 **KorFin-ASC**(사람 라벨, CC BY-SA 4.0) 일부를 같은 감성 지시로 분류해 정확도 | 0 |
| ⑦ 감성 바깥 기준 2 | 코드 | 호재·악재로 판단한 기사의 **다음 거래일 주가 방향**과 비교 (KIS 일봉, 탐색용) | 0 |
| ⑧ 봉인 시험 | 마지막 한 번 | 개선을 다 끝낸 뒤 시험용 100건으로 **한 번만** 채점. 그 전에는 열어 보지 않음 | 0 |

순서: ③④(답 안 보는 직접 라벨)를 **먼저**, ⑤(답을 보는 검수)를 나중에. 검수를 먼저 하면 직접 라벨이 답에 끌려감.

무엇을 재나:
- **사람끼리 일치도** (③ vs ④): 연결 쌍별 F1 (= positive specific agreement, Hripcsak & Rothschild 2005), 역할 Cohen's κ → "지침서가 사람마다 같게 읽히는가"
- **사람 vs LLM** (③④ vs ②): 같은 지표 → "LLM 정답지를 믿어도 되는가"
- **검수 동의율** (⑤): 연결 Precision 쪽 근거. 함정 5개 중 몇 개를 잡았는지 함께 (답을 그냥 따라가지 않았다는 증거). 함정은 동의율 계산에서 뺌
- 숫자마다 Wilson 95% 신뢰구간

목표 (넘으면 LLM 정답지를 쓰고, 못 미치면 기준을 고쳐 ②를 다시):
- 사람끼리 연결 F1 ≥ 0.8, 사람 vs LLM 연결 F1 ≥ 0.8, 검수 동의율 ≥ 90%
- 해석 관례: κ 0.61~0.80 "상당한 일치", 0.81 이상 "거의 완전한 일치" (Landis & Koch 1977)

보고하는 문장 (사실 그대로):
> "정답지는 LLM 이 지침서대로 라벨을 붙였다. 비전문가 2명이 같은 20건을 따로 라벨해 사람끼리 연결 일치도 F1 a, 사람과 LLM 사이 b 였고, 30건 검수에서 동의율 c% (함정 5개 중 d개 적발). 감성은 공개 데이터셋 KorFin-ASC 에서 e%, 다음 거래일 주가 방향과 f% 일치했다."

한계 (먼저 밝힘):
- 사람은 비전문가 2명, 직접 라벨은 20건이라 신뢰구간이 넓음
- 검수는 답을 보는 방식이라 놓친 회사(Recall)는 잘 안 잡힘 (Fort & Sagot 2010) → Recall 근거는 ③④ 직접 라벨로
- KorFin-ASC 는 뉴스 제목 문장 단위라 우리 정의(기사 전체·다음 거래일)와 다름 → 보조 근거
- 근거 연구: LLM 라벨 + 사람 확인 방식 (Wang et al., CHI 2024), 평가 모델과 채점 모델을 다른 회사로 (Panickssery et al., NeurIPS 2024: LLM 은 자기 글을 더 좋게 채점)

## 6. 채점 (시스템 vs 정답지)

| 지표 | 계산 | 보고 |
|---|---|---|
| 연결 Precision·Recall | 기사×종목 쌍 (v1 6절과 같음) | Wilson 95% 신뢰구간 함께 |
| 역할 일치 | 맞은 연결끼리 주인공/당사자/비교 | κ |
| 감성 | 맞은 연결끼리. 판단 보류 = 시스템 NULL 과 같게 봄 | 일치율, κ, 혼동표 |
| 근거 문장 | 시스템 근거가 정답 근거 문장과 같거나, 그 종목·사실이 들어 있는 문장인가 | 비율 |
| 묶음별 | 종목 1개 / 2개 이상 기사, 주인공 / 그 밖 | 멘토 지적 (a) 를 따로 보이게 |
